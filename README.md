# 🐔 Poultry360 | Smart Broiler Management & Analytics

**Poultry360** is a professional, data-driven broiler farm management web application tailored for Zambian agricultural operations. Built with a modern dark UI, it integrates Excel tracking workbooks, a secure SQLite backend, and dynamic Plotly analytics to track flock performance, health schedules, financials, and Feed Conversion Ratios (FCR).

---

## 🚀 Tech Stack
* **Frontend / UI**: Streamlit (GitHub-inspired Dark Mode UI)
* **Backend & Data**: Python 3.12+, SQLite, Pandas
* **Data Visualization**: Plotly Express
* **Workbook Parsing**: Openpyxl

---

## ✨ Core Features
1. **Excel Workbook Import & Parsing**: Seamlessly ingests legacy tracking sheets into a structured relational database.
2. **Farm Performance Dashboard**: Real-time metrics tracking active batches, initial/current bird populations, and mortality trends.
3. **Flock & Daily Records Management**: Interactive CRUD modules for logging daily mortality, feed intake, and average body weight.
4. **Health & Vaccination Logs**: Tracks Gumboro, Newcastle, vitamin, and anti-stress administration schedules.
5. **Financial Ledger & P&L**: Monitors feed costs, medication expenses, and projected revenues in Zambian Kwacha (ZMW).
6. **Advanced Analytics & FCR**: Calculates Feed Conversion Ratio (FCR) and visualizes growth curves against standard agricultural benchmarks.
